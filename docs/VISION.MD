# Vision

## Goal

Create a migration tool that converts RemNote exports into a Markdown/Obsidian knowledge vault while preserving as much structure, metadata, references, and context as possible.

The resulting vault should be optimized both for human knowledge work and for AI agents working with the knowledge base as context.

## Target User

Primary target user:

- Daniel Kopecký

Secondary target users:

- technically skilled users migrating from RemNote to Obsidian
- users building AI-assisted personal knowledge systems
- users who want portable and vendor-independent knowledge storage

## Value

The project provides:

- migration away from vendor lock-in
- long-term ownership of knowledge in Markdown
- structured knowledge usable in Obsidian
- preservation of relationships and metadata from RemNote
- AI-readable context for agents and automation
- a foundation for future personal knowledge infrastructure

## Non-Goals

This project will NOT:

- fully recreate the RemNote application
- perfectly reproduce all RemNote features
- implement full spaced repetition behavior
- provide bidirectional synchronization
- optimize notes semantically in the first version
- become a generic PKM platform
